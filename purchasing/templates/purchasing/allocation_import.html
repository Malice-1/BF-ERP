Préparer le fichier

Télécharger le modèle Excel

La feuille « Allocations » contient les montants actuels de cette version. Les autres feuilles fournissent les codes BI, CDF et financements disponibles.

Renseignez une ligne par combinaison, avec les colonnes Code BI, Code CDF, Code financement et Montant TVAC. Conservez les codes comme texte, notamment leurs zéros initiaux. Utilisez des valeurs numériques, sans formules.

Chaque montant représente le budget total de la combinaison : l’import crée les lignes absentes et remplace le montant des lignes présentes dans le fichier. Les autres allocations de la version sont conservées. Réimporter les mêmes montants ne les additionne pas.

Le fichier doit être au format .xlsx, de 5 Mo maximum et de 10 000 lignes maximum. Si une ligne est invalide, aucune modification n’est enregistrée. L’import ne publie pas la version.
